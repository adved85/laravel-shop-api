================

================================================================
1. CREATE THE LARAVEL PROJECT
================================================================

Start Devilbox and enter the shell:

    $ docker-compose up -f
    $ ./shell.sh

Create the project directory and install Laravel:

    $ mkdir laravel-shop-api
    $ cd laravel-shop-api
    $ composer create-project laravel/laravel laravel-shop-api

    After updating Devilbox for PHP 8.3/8.4 → Laravel 13.8.0 was installed.


================================================================
2. LOCAL DOMAIN SETUP
================================================================

Map the domain in /etc/hosts (run on the host machine, not inside Devilbox):

    $ sudo nano /etc/hosts

Add:
    127.0.0.1   laravel-shop-api.dvl.to

Local URL: http://laravel-shop-api.dvl.to:88
    (port changed from 80 to 88 — port 80 is occupied on the host machine)

Devilbox port config  →  devilbox/.env:
    HOST_PORT_HTTPD=88
    HOST_PORT_HTTPD_SSL=443

Create the Devilbox symlink (required when the project was created manually,
not by Devilbox itself):

    $ ln -s laravel-shop-api/public/ htdocs

================================================================
4. DATABASE SETUP  (PostgreSQL)
================================================================

Configure .env:

    DB_CONNECTION=pgsql
    DB_HOST=127.0.0.1
    DB_PORT=5432
    DB_DATABASE=laravel_shop_api
    DB_USERNAME=postgres
    DB_PASSWORD=

Create the database (run in pgAdmin or DBeaver query tool):

    CREATE DATABASE laravel_shop_api
        ENCODING = 'UTF8'
        TEMPLATE = template0;

Run migrations:

    $ php artisan migrate

--- pgAdmin 4 connection ---
    Host:      pgsql  (or localhost:88 from the browser)
    Port:      5432
    Database:  laravel_shop_api
    User:      postgres
    Password:  (none for the postgres superuser)

    pgAdmin master password (local only): pgadmin4

--- DBeaver connection ---
    Host:      127.0.0.1
    Port:      5432
    Database:  laravel_shop_api
    User:      postgres
    Password:  (none)

    See resources.txt for DBeaver download and feature overview.

--- Reset the database ---
    -- SQL (drop and recreate all tables):
    DROP SCHEMA public CASCADE;
    CREATE SCHEMA public;

    -- or via Artisan:
    $ php artisan migrate:fresh


================================================================
5. USERS TABLE — system_role ENUM
================================================================

Add a role column to the users migration:

    $table->enum('system_role', ['admin', 'owner', 'customer'])
          ->default('customer');
